# Sample / DEMO data

Generated by `python -m nids.demo` (also invoked from `./start.sh`).

| File | Contents |
| --- | --- |
| `lab-demo.pcap` | Synthetic lab traffic (RFC1918 + TEST-NET-3 `203.0.113.0/24`) |
| `eve.json` | Suricata-style EVE alerts, every record has `"demo": true` |
| `zeek/conn.log` `dns.log` `http.log` `ssl.log` | Minimal Zeek TSV for the importer |

All IDS rows loaded into the dashboard are tagged `is_demo=1` and rendered with a **DEMO** pill.

Do not treat DEMO signatures as evidence of a real intrusion.
